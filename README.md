# Pi Calculator

Визуальное веб-приложение на `Spring Boot + React`, которое показывает процесс вычисления числа `Pi` в реальном времени. Каждая цифра появляется отдельно, крупным шрифтом, а над ней отображается время, за которое эта цифра была получена с начала вычисления.

## Что умеет проект

- вычисляет цифры числа `Pi` по одной;
- показывает цифры в браузере в виде горизонтальной ленты;
- над каждой цифрой отображает накопленное время вычисления;
- позволяет задать количество цифр после запятой;
- позволяет задать задержку между выводом цифр для красивой анимации;
- запускается локально через `Gradle` или в `Docker`;
- работает на порту `8181`.

## Технологии

- `Java 21`
- `Spring Boot 4`
- `Spring Web`
- `Server-Sent Events (SSE)` для потока цифр из backend в frontend
- `React 18` для клиентского интерфейса
- `Gradle` для сборки
- `Docker` для контейнерного запуска

## Структура проекта

- `src/main/java/org/example/picalculator` — запуск Spring Boot приложения
- `src/main/java/org/example/picalculator/pi` — генерация цифр `Pi` и SSE-контроллер
- `src/main/resources/static` — frontend интерфейс

## Как запускать проект

### Основной способ запуска

Требуется:

- установленный и запущенный `Docker Desktop`

Запуск одной командой:

```powershell
powershell -ExecutionPolicy Bypass -File .\run-docker.ps1
```

Что делает эта команда:

- собирает Docker-образ приложения;
- поднимает Docker-контейнер `pi-calculator-container`;
- публикует приложение на порту `8181`;
- ждёт, пока приложение станет доступно;
- автоматически открывает окно браузера со страницей программы.

После выполнения команды приложение должно открыться автоматически по адресу:

```text
http://localhost:8181/
```

### Альтернативный запуск без Docker

Требуется:

- установленный `JDK 21`

Команда запуска:

```powershell
.\gradlew.bat bootRun
```

После запуска страницу нужно открыть вручную:

```text
http://localhost:8181/
```

### Проверка, что контейнер действительно работает

Список контейнеров:

```powershell
docker ps
```

Логи приложения:

```powershell
docker logs pi-calculator-container
```

Остановка контейнера:

```powershell
docker rm -f pi-calculator-container
```

## Как пользоваться

1. Откройте страницу `http://localhost:8181/`.
2. Укажите количество цифр после запятой.
3. Укажите задержку между цифрами в миллисекундах.
4. Нажмите `Старт`.
5. Следите, как цифры `Pi` появляются по одной.

Кнопка `Стоп` завершает текущий поток.

## Принцип работы

Приложение состоит из двух частей:

### Backend

Backend на `Spring Boot`:

- вычисляет цифры числа `Pi`;
- формирует событие для каждой цифры;
- отправляет эти события в браузер через `SSE`.

Каждое событие содержит:

- порядковый номер символа;
- сам символ, например `3`, `.`, `1`;
- время в миллисекундах от начала вычисления до появления этого символа.

### Frontend

Frontend:

- открывает `EventSource` на endpoint `/api/pi/stream`;
- получает цифры по мере вычисления;
- добавляет каждую цифру в интерфейс;
- автоматически прокручивает ленту вправо по мере роста числа.

## Алгоритм вычисления числа Pi

В проекте используется spigot-алгоритм для десятичного разложения числа `Pi`.

Его идея:

- цифры вычисляются последовательно, слева направо;
- не нужно заранее получать всю строку числа `Pi`;
- каждая новая цифра появляется независимо, что удобно для потоковой визуализации;
- алгоритм хранит промежуточные остатки во внутреннем массиве и постепенно уточняет следующую цифру.

Почему выбран именно он:

- хорошо подходит для показа цифр по одной;
- не требует сложной арифметики с большими десятичными строками на каждом шаге;
- естественно сочетается с `SSE`, где удобно отправлять результат по мере вычисления.

## Основные endpoint'ы

- `GET /` — интерфейс приложения
- `GET /api/pi/stream?digits=300&delayMs=35` — поток цифр `Pi`
